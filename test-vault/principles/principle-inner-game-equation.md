# Inner Game Equation

## Rule
The objective of coaching is to improve Performance (P) by growing a person's potential (p) and decreasing interference (i), as summarized by the equation: $$P = p - i$$

## Rationale
The equation works because it shifts focus from external instruction to the internal state of the learner. Gallwey claimed that if a coach helps reduce a person's internal obstacles, an "unexpected natural ability to learn and to perform will occur" without the need for much direct technical input. This is grounded in the view that people have a "built-in, natural learning capability" that coaching aims to unlock by minimizing interference.
