# Outcome Ladder

## Definition
The **Outcome Ladder** is a model for categorizing different levels of learning and performance outcomes. It separates outcomes into four ascending "rungs": remembering, recognizing, performing, and transferring a skill or knowledge in increasingly complex and realistic contexts.

## Operationalization
The model is operationalized as a four-rung ladder. Each rung is defined by a specific, observable outcome:
*   **Rung A (remember):** The learner can recall terms or facts.
*   **Rung B (recognize):** The learner can pick the correct option from a set of examples.
*   **Rung C (perform):** The learner can execute the target behavior in a realistic scenario.
*   **Rung D (transfer):** The learner can apply the skill later, in a different context, and under stress or pressure.

The model is used within the [[7-Minute Microlearning Loop]] by choosing one specific rung as the target for a learning unit and writing an "observable pass condition" for it.

## Boundary conditions
The model is applied in the context of designing microlearning to combat [[Interference (Learning)]] and ensure skills "stick" for real-world application, such as preparing managers for difficult conversations. A common failure mode is applying the model incorrectly by only testing at Rung A (remember) and assuming higher-level performance has been achieved. Not specified in this source. Open questions: (1) Is the ladder strictly hierarchical, or can steps be skipped? (2) Are there skills for which the "transfer" rung is not a relevant goal?
