# Calibration Loop

## Rule
To improve [[Calibration]] fastest, a learner must commit to a decision before seeing the answer, and the feedback must explicitly name the hidden variable (e.g., risk, trust, time, power, or uncertainty) that explains the difference between their choice and an expert's choice.

## Rationale
This principle leverages deliberate comparison and explicit feedback to correct a learner's internal model. It counters the misconception that recognition equals performance. By requiring a committed choice, it forces the learner to apply their current judgment, creating a clear gap for feedback to address. Naming the hidden variable provides a concrete, transferable rule of thumb for future decisions, accelerating learning and improving performance under constraints.
