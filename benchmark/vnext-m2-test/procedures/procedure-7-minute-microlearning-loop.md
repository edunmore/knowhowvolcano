# 7-Minute Microlearning Loop

## When to use
Use this loop to design a single microlearning unit that aims to turn internal know-how into actionable skills. It is intended to overcome the problem of *interference*, where learners freeze under pressure, forget steps, or choose the wrong tool. It is a reusable toolbox for creating short learning units that target specific performance outcomes.

## Steps
1.  **Choose one [[Outcome Ladder]] rung as the target** (A: remember, B: recognize, C: perform, or D: transfer).
2.  **Write one “observable pass condition”**—a measurable or visible indicator of success.
3.  **Create one short scenario with a constraint** (e.g., time pressure, an annoyed colleague, missing data).
4.  **Offer two actions**: the intended action and a tempting wrong action.
5.  **Ask for a choice *and* a one-sentence reason** for that choice.
6.  **Give [[Two-Speed Feedback]]**: first a short rule of thumb, then a deeper explanation.
7.  **Add a “next repetition” prompt**: specify when and how to repeat the practice (e.g., tomorrow, next meeting, next real case).

## Failure modes
A common failure is testing only the "remember" (Rung A) level of the [[Outcome Ladder]] and celebrating progress while real-world performance stays flat. Another mistake is adding too much content, which raises [[Friction Budget|friction]] without improving [[Transfer|transfer]]. If the friction budget is exceeded, learners default to superficial reading instead of deliberate practice.
