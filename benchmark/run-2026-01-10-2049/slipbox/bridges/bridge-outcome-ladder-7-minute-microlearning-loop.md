# Bridge: Outcome Ladder ↔ 7-Minute Microlearning Loop

The Outcome Ladder and the 7-Minute Microlearning Loop are complementary frameworks for structured learning. The Ladder provides the "why" and destination—a clear hierarchy of goals from foundational tasks to ultimate objectives. The Loop provides the "how"—a rapid, repeatable cycle (Expose, Engage, Enact, Evaluate) to build skills.

Use them together when designing or undertaking a skill-building journey. Start by climbing the Outcome Ladder to define a specific, immediate rung as your target (e.g., "I can write a clear project status email"). Then, use the 7-Minute Loop to create or select a micro-session that directly practices that exact skill. Each completed Loop propels you up one rung.

The key insight is that microlearning needs macro-direction. The Loop ensures efficient, engaging practice, while the Ladder ensures those minutes accumulate meaningfully toward a larger, motivating competency, preventing fragmented learning. Together, they turn brief sessions into a coherent path to mastery.
