# Common Mistake Testing Only Recall

## Rule
A common mistake in learning design is to test only for recall ([[Rung A (Outcome Ladder)|Rung A]]) and celebrate progress while real-world performance stays flat.

## Rationale
Testing only recall (the ability to remember terms) fails to ensure learners can [[Perform (Outcome Ladder)|perform]] the behavior in realistic scenarios or [[Transfer (Outcome Ladder)|transfer]] the skill to different contexts under stress. This creates a false sense of progress, as [[Recognition (Outcome Ladder)|recognition]] is not performance. [[Transfer (Outcome Ladder)|Transfer]] requires [[Deliberate Practice|deliberate practice]] against realistic constraints, not just superficial reading or recall.
