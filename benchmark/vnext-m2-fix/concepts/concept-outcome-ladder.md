# Outcome Ladder

## Definition
The Outcome Ladder is a framework that separates learning outcomes into four distinct levels or "rungs," from basic recall to complex application. It is used to define what success looks like for a learner in the real world, moving from remembering terms to transferring a skill to a new context under pressure.

## Operationalization
The ladder is operationalized by its four rungs:
- **Rung A: remember** – The learner can recall terms.
- **Rung B: recognize** – The learner can pick the correct option from examples.
- **Rung C: perform** – The learner can execute the behavior in a realistic scenario.
- **Rung D: transfer** – The learner can apply the skill later, in a different context, and under stress.
An "observable pass condition" should be written to measure achievement of the target rung.
