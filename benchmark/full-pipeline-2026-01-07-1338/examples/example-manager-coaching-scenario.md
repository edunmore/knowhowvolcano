# Manager Coaching Scenario

## Scenario
A manager is approached by a team member who says, “I keep missing deadlines because other teams block me.” The manager is presented with two possible actions to take in response.

## Context
The situation is a typical managerial coaching moment where a direct report presents a recurring problem. The Source Text does not specify additional details about the team, company, or specific project pressures, but it implies this is a common scenario for practicing [[Managerial Decision-Making]].

## Key Insight
This example illustrates the principle of **diagnosis before advice**. The correct action is to first explore the problem with a concrete example to understand the constraints, rather than jumping to a solution. This prevents triggering defensiveness and addresses the root cause.

## Structure
- **Setup:** A team member reports a recurring issue with missed deadlines due to other teams.
- **Tension:** The manager must choose between a diagnostic approach (Action A) and an immediate advice-giving approach (Action B).
- **Resolution:** The intended correct action is Action A: "Ask for a concrete recent example and explore constraints before proposing a solution."
- **Outcome:** Action B, which is tempting because it feels helpful, is a common mistake as it skips the diagnostic step and can trigger defensiveness. This demonstrates the need for structured [[Calibration Loop|calibration]] in decision-making.

## Rewrite Opportunity
- **Core Pattern:** The pattern is "Problem Report -> Tempting Quick Fix vs. Diagnostic Inquiry -> Correct Diagnostic Choice."
- **Transferable Elements:** This structure can be adapted to any coaching or problem-solving domain where a subordinate presents a systemic issue. The key transferable element is forcing a pause for diagnosis before solutioneering. The constraint (e.g., time pressure, annoyed colleague) can be varied to practice [[Skill Transfer Under Constraint|skill transfer]].
- **Open Questions:** (1) How would this scenario change under explicit time pressure? (2) What specific question phrasing makes the diagnostic step most effective?
