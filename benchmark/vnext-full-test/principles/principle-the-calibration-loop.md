# The Calibration Loop

## Rule
[[Calibration]] improves fastest when the learner must commit to a decision before seeing an expert answer, and when the feedback explicitly names the hidden variable (e.g., risk, trust, time, power, or uncertainty).

## Rationale
This process forces learners to compare their own choice against an expert benchmark, focusing the learning on understanding the gap. By requiring a prior commitment, it counters superficial engagement. By naming the hidden variable, feedback provides a conceptual anchor for the rule of thumb, moving beyond rote correction to build a more adaptable [[Mental Model]].
