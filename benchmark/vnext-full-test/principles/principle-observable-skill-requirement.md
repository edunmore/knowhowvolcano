# Observable Skill Requirement

## Rule
When designing a learning unit, write one "observable pass condition"—a clear, measurable action or choice you can see the learner make to confirm they've met the target skill.

## Rationale
This requirement grounds the learning objective in a concrete, verifiable outcome, preventing the common trap of creating "nice-to-read" content that doesn't translate to performance. It is a core step in the [[7-Minute Microlearning Loop]] and is tied to a specific rung on the [[Outcome Ladder]], ensuring that success is defined by what the learner can *do*, not just what they can recall or recognize.
