# Outcome Ladder

## Definition
The **Outcome Ladder** is a model for categorizing learning outcomes into four hierarchical levels, or rungs. It separates what a learner can do, from simply recalling information to performing a behavior under real-world constraints and stress.

## Operationalization
The ladder is operationalized by its four distinct rungs:
- **Rung A: Remember** – The learner can recall terms or facts.
- **Rung B: Recognize** – The learner can identify the correct option from a set of examples.
- **Rung C: Perform** – The learner can execute the target behavior in a realistic practice scenario.
- **Rung D: Transfer** – The learner can apply the skill later, in a different context, and under pressure (e.g., stress, time constraints).

Not specified in this source. Open questions: (1) Is the progression between rungs always linear or can learners skip levels? (2) Does the model apply to all types of skills (e.g., cognitive, psychomotor, affective) equally?
