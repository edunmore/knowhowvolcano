# The Calibration Loop

## Rule
A learner calibrates fastest when they must commit to a decision before seeing the answer, and when the feedback they receive explicitly names the hidden variable (e.g., risk, trust, time, power, or uncertainty) that explains the difference between their choice and an expert choice.

## Rationale
This process accelerates learning by forcing a concrete, accountable prediction, which creates a clear point of comparison. The feedback layer that identifies a specific hidden variable provides a mental model for the underlying reasoning, moving beyond simple right/wrong answers to build deeper [[Expert Judgment]]. This combats the misconception that recognition equals performance, as true [[Transfer (Learning)]] requires practice under constraint.
