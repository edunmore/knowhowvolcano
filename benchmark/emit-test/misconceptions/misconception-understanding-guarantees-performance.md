# Understanding Guarantees Performance

## Misconception
The wrong belief is that if a learner understands or recognizes a concept or model once, they will be able to perform the related skill later in a real-world situation. This is the assumption that comprehension directly and automatically leads to [[Transfer]].

## Why it happens
The source text suggests this misconception arises because "recognition is not performance." It is easy to test for comprehension (e.g., Rung A of the [[Outcome Ladder]]) and celebrate progress, while actual performance remains unchanged. The cognitive ease of nodding along with a good model can be mistaken for the ability to apply it.

## Correction
True performance requires more than initial understanding. According to the source, "Transfer requires repetition spaced over time and practice under constraints." Effective learning design must move beyond recognition to include [[Deliberate Practice]] in scenarios with constraints like time pressure or stress. The [[7-Minute Microlearning Loop]] and [[Calibration Loop]] are tools designed to build this kind of transferable skill.
