# Outcome Ladder

## Definition
The **Outcome Ladder** is a model for classifying learning outcomes into four distinct levels or "rungs," ranging from basic recall to complex application under stress. It separates what a learner can do at each level to help designers target the right level of performance.

## Operationalization
The ladder is operationalized as four ascending rungs:
*   **Rung A: Remember** – The learner can recall terms and facts.
*   **Rung B: Recognize** – The learner can pick the correct option from a set of examples.
*   **Rung C: Perform** – The learner can execute the behavior in a realistic practice scenario.
*   **Rung D: Transfer** – The learner can apply the skill later, in a different context, and under pressure or stress.

An "observable pass condition" should be written for the targeted rung during the [[7-Minute Microlearning Loop]].

## Boundary conditions
The model is presented as a tool for designing [[Microlearning]] units to combat *interference*, where learners fail in real situations despite knowing the theory. It is implied to apply when defining success for skill-based training (e.g., for new managers). A common failure mode is designing assessments that only test Rung A (remember) while assuming this leads to performance (Rung C or D).
