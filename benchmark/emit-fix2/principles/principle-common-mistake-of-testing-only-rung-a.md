# Common Mistake of Testing Only Rung A

## Rule
A common instructional design mistake is to create assessments that only test **Rung A (remember)** of the [[Outcome Ladder]], leading to a false sense of progress while real-world performance remains unchanged.

## Rationale
Testing only for recall (Rung A) fails to build the skills needed for actual application. True performance (Rung C) and [[Transfer (Learning)]] (Rung D) require practice under realistic constraints like [[Time Pressure]] or [[Stress Response]]. Celebrating progress on recall alone misdiagnoses the root cause of performance gaps, which is often [[Interference]] in real situations, not a lack of motivation or initial understanding.
