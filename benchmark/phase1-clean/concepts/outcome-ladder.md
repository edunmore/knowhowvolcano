# Outcome Ladder

## Definition
The Outcome Ladder is a framework for categorizing learning outcomes into four distinct levels of competence, from basic recall to the ability to apply a skill in novel, high-pressure situations. It is used to clarify what successful performance looks like in the real world and to prevent the common error of celebrating progress on lower-level outcomes while real-world performance remains unchanged.

## Key Components
The framework defines four ascending levels:
- Level 1 (author's "Rung A"): Remember - The learner can recall terms and definitions.
- Level 2 (author's "Rung B"): Recognize - The learner can identify the correct option or principle from given examples.
- Level 3 (author's "Rung C"): Perform - The learner can execute the target behavior in a realistic, controlled scenario.
- Level 4 (author's "Rung D"): Transfer - The learner can apply the skill later, in a different context, and under stress or pressure.

## Application
The ladder is used to define the target outcome for a learning unit, such as within the [[7-Minute Microlearning Loop]]. A key instructional mistake is designing assessments that only test Level 1 (Recall) while the actual need is for Level 3 (Perform) or Level 4 (Transfer). It helps designers focus practice and feedback on achieving the desired level of real-world competence.
