# Prefer Fewer, Stronger Links

## Rule
A note system should connect ideas so that a learner or author can move from one note to the next without reading everything. However, links should be used selectively, pointing only to stable concepts, named models, or repeated prerequisites. Avoid linking every noun.

## Rationale
Linking every noun creates noise and reduces the utility of the system. Stronger, fewer links improve navigation and learning by connecting to foundational and recurring ideas, allowing users to traverse knowledge efficiently. Other concepts can remain as plain text until they prove useful enough to warrant a formal link.
