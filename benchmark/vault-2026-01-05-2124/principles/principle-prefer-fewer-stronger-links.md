# Prefer Fewer, Stronger Links

## Rule
In a note system, create links only to stable concepts, named models, or repeated prerequisites. Avoid linking every noun, as this creates noise. The goal is to enable a learner or author to move from one note to another without having to read everything in between.

## Rationale
This principle aims to reduce noise and improve the signal in a knowledge network. The source text states that "linking every noun creates noise." Stronger, more intentional links facilitate efficient navigation and deeper understanding by connecting core, enduring ideas rather than transient details.
