# 7-Minute Microlearning Loop

## When to use
Use this loop to design one learning unit. The source provides an example context of turning internal know-how into short learning units for new managers, but the procedure itself is presented as a general design tool.

## Steps
1. Choose one Outcome Ladder rung as the target (A, B, C, or D).
2. Write one "observable pass condition" (what you can see or measure).
3. Create one short scenario with a constraint (time pressure, an annoyed colleague, missing data).
4. Offer two actions: the intended action and a tempting wrong action.
5. Ask for a choice *and* a one-sentence reason.
6. Give feedback in two layers: first a short rule of thumb, then a deeper explanation.
7. Add a "next repetition" prompt: when and how to repeat (tomorrow, next meeting, or next real case).

## Failure modes
Not specified in this source. Open questions: (1) What is the consequence of choosing a scenario constraint that does not match the target Outcome Ladder rung? (2) How does the Friction Budget interact with the loop's prescribed seven steps?
