# Prefer Fewer, Stronger Links

## Rule
When designing a [[Note System]], create links only to stable, foundational concepts (like named models or repeated prerequisites) rather than linking every noun. Avoid creating noise by leaving less useful terms as plain text until they prove their utility.

## Rationale
A note system should enable efficient navigation from one idea to the next without requiring the learner to read everything. Over-linking creates noise, which can distract from the core learning path. Stronger links to stable concepts provide clearer, more valuable connections that support knowledge transfer and reduce cognitive [[Friction Budget|Friction]].
