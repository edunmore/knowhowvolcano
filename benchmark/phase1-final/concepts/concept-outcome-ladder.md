# Outcome Ladder

## Definition
The Outcome Ladder is a framework for categorizing learning outcomes based on the level of cognitive and behavioral complexity required for real-world application. It helps designers move beyond assessing simple recall to targeting and measuring actual performance and transfer under realistic conditions.

## Key Components
The ladder consists of four progressive stages, abstracted from the author's specific "rungs":
- **Level 1 (author's "Rung A")**: Remember – The learner can recall terms or facts.
- **Level 2 (author's "Rung B")**: Recognize – The learner can identify the correct option or principle from given examples.
- **Level 3 (author's "Rung C")**: Perform – The learner can execute the target behavior within a structured or simulated scenario.
- **Level 4 (author's "Rung D")**: Transfer – The learner can apply the skill later, in a different context, and under pressure or stress.

## Application
The framework is used to define the target outcome for a learning unit, ensuring that assessment matches the desired real-world capability. A common mistake is designing learning that only tests Level 1 (Recall) while the actual goal is performance or transfer. It is a core component of the [[7-Minute Microlearning Loop]], where the first step is to select a target level from this ladder.
