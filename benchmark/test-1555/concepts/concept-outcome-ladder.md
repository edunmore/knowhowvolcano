# Outcome Ladder

## Definition
The **Outcome Ladder** is a model that separates learning outcomes into four hierarchical "rungs," each representing a different level of capability. It is used to define what success looks like for a learner in the real world, moving from basic recall to complex application.

## Operationalization
The ladder is operationalized by its four distinct rungs:
*   **Rung A: Remember** – The learner can recall terms or facts.
*   **Rung B: Recognize** – The learner can pick the correct option from given examples.
*   **Rung C: Perform** – The learner can execute the behavior in a realistic scenario.
*   **Rung D: Transfer** – The learner can apply the skill later, in a different context, and under pressure or [[Stress Response|stress]].

Each rung can be targeted by writing a specific "observable pass condition" as part of a [[7-Minute Microlearning Loop]].

## Boundary conditions
The ladder is presented as a tool for designing [[Microlearning]] to prevent [[Interference]] in performance. It is specifically used to counteract the common mistake of testing only the lower rungs (like recall) and celebrating progress while real-world performance remains flat. The source does not specify if the model applies to all types of learning or knowledge domains.
