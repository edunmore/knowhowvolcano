# Spend Friction Where It Buys Transfer

## Rule
In learning design, cognitive effort (friction) should be strategically allocated only to activities that demonstrably contribute to the learner's ability to apply skills in new contexts (transfer).

## Rationale
Every learning unit has a limited "Friction Budget"; exceeding it causes learners to disengage from deliberate practice. The principle counters the misconception that "more content means more learning," as extra content can raise friction without improving transfer. Therefore, friction is a resource to be invested, not minimized, but only in steps that purchase higher-level outcomes like performance and [[Transfer (Learning Outcome)]].
