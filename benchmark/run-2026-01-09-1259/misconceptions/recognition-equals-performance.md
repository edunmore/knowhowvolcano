# Recognition Equals Performance

## Misconception
The wrong belief that if a learner can understand or recognize a correct model or answer in a learning context, they will be able to perform the associated skill in a real-world situation later.

## Correction
Recognition is not performance. True performance, especially the ability to transfer a skill to a different context under stress, requires deliberate practice under constraints and spaced repetition over time. [[The Outcome Ladder]] clarifies that recognition (Level 2: Recognize) is a lower-order outcome than performance (Level 3: Perform) and transfer (Level 4: Transfer).
