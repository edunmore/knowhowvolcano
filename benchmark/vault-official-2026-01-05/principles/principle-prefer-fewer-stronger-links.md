# Prefer Fewer, Stronger Links

## Rule
A note system should connect ideas so that a learner or author can navigate from one note to the next without reading everything, but links should be used sparingly. Links should point to stable concepts, named models, or repeated prerequisites. Everything else should be left as plain text until it proves useful.

## Rationale
Linking every noun creates noise. By focusing on fewer, stronger links, the system maintains navigational utility without the clutter of excessive connections.
