# The Inner Game

## Definition
The Inner Game is a concept from modern coaching, introduced by Timothy Gallwey. It refers to the internal state of a player, where the primary obstacle to performance is "the opponent within one's own head." The concept is captured by the equation Performance = Potential – Interference, where the goal is to improve performance by reducing internal interference.

## Operationalization
The Inner Game can be observed when a coach helps a player remove or reduce internal obstacles. A key indicator is when a player's "unexpected natural ability to learn and to perform will occur without the need for much technical input from the coach." The central equation, P = p – i, provides a framework for focusing efforts on decreasing interference (i).
