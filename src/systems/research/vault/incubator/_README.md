# Incubator Directory

This folder contains **candidate notes** - weak mentions and terms that don't yet meet the permanent-note bar.

## Lifecycle

- Notes start here with `status: candidate`
- When evidence accumulates, they can be promoted to `slipbox/` with `status: grounded`
- If a candidate duplicates an existing note, it becomes a `redirect`
