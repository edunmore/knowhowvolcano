## BRIDGE NOTE GENERATION (SYNTHESIS)

Create short bridge notes that connect 2–3 existing notes with an explicit claim.
Rules:
- Mark the note as synthesized (not a source quote).
- Use links to the connected notes.
- State the connective claim in one paragraph, then give a practical implication for education/content generation.
- Insert each bridge note into at least one strand and reference it from a relevant MOC.
