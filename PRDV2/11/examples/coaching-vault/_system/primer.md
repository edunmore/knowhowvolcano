# Coaching Knowledge Vault — Primer

## What this vault is for
This vault stores paraphrased, teachable coaching knowledge for education and content generation.

## How to write notes
Write actionable notes: define the concept, explain when to use it, how to apply it, and where it fails. Include pitfalls and an example. Use neutral educator tone. Do not copy source text.

## Links and stubs
Whenever a term appears as presumed knowledge, add a link intent like [[Psychological Safety]] or [[SMART Goals]]. If the target note does not exist yet, it will be created later as a stub.

## What to skip
Skip marketing copy, author biography, acknowledgements, and unrelated front matter.
