# Inner Game

## Definition
The Inner Game is a framework introduced by Timothy Gallwey that focuses on the internal psychological state of a performer. It posits that the primary obstacle to performance is not a lack of technical skill, but the "opponent within one's own head"—the internal obstacles and interference that inhibit an individual's natural potential.

## Operationalization
The framework is operationalized through the Inner Game Equation: Performance = Potential – Interference (P = p - i). Coaching within this framework involves a coach helping an individual to identify and reduce internal interference (i). This reduction allows the individual's inherent potential (p) to be more fully expressed, thereby improving performance (P). The source describes this as helping a player "remove or reduce the internal obstacles to performance," after which "an unexpected natural ability to learn and to perform will occur."

## Boundary conditions
