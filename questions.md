Definition

The Inner Game is a concept from [[Timothy Gallwey]] describing the player’s internal state during performance. It holds that the “opponent within one’s own head” can be more challenging than the external opponent. The practical aim is to improve performance by reducing [[Interference]], so that learning and capability can emerge more naturally.

Operationalization

The concept is operationalized through the [[Inner Game Equation]]: [[Performance]] = [[Potential]] − [[Interference]] (P = p − i). Framed as a coaching goal, this means improving performance by increasing potential and reducing interference.
